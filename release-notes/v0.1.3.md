# Wren Companion 0.1.3

This update makes site connection retries more reliable.

- Connection checks stop after three seconds so a new attempt can proceed.
- Late replies cannot cancel a retry or change its network.
- The active network updates after the connection checks succeed.
- Sites can request a network change when their assigned network is disabled.

Transaction and approval requests keep their existing wait behavior.
Pairing protocol 3, permissions, and data types are unchanged.
Use Wren 0.1.11 or a later compatible desktop build.
