# Wren Companion 0.1.0

Wren Companion connects browser-based Ethereum and EVM dapps to the Wren
desktop wallet. Wren keeps accounts, signers, approvals, and transaction review
in the desktop application; the extension provides EIP-1193 and EIP-6963 browser
discovery and routes each document's requests to Wren on the same computer.

## Highlights

- Separate Chrome and Firefox Manifest V3 packages.
- Explicit six-digit pairing with mutually authenticated protocol-3 reconnects.
- Tab, frame, document, and origin isolation for requests, responses, events,
  subscriptions, and pairing authority.
- Per-site Wren/legacy-provider presentation and Wren-controlled chain switching.
- No analytics, advertising, telemetry, remote code, cloud account, or
  developer-operated data service.

## Files

- `wren-companion-0.1.0-chrome.zip`
- `wren-companion-0.1.0-firefox.zip`
- `wren-companion-0.1.0-source.zip` for Mozilla review
- compatibility metadata, production SBOM, and `SHA256SUMS`

The installable packages require a compatible Wren desktop release. Browser
store review and publication are separate from this GitHub release.

## Release boundary

Use disposable browser profiles and accounts for initial testing. The extension
requires HTTP and HTTPS site access so it can inject the wallet provider on dapp
pages, and it communicates wallet requests only with Wren at
`ws://127.0.0.1:1248`. See the privacy policy, security notes, compatibility
metadata, and reviewer build instructions in this repository.
