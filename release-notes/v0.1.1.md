# Wren Companion 0.1.1

This policy-remediation release removes the browser name and runtime extension
UUID from Companion authentication messages. Pairing continues to use the
signed installation ID and separate control/page P-256 keys; Wren validates the
browser-supplied WebSocket Origin only for the live connection and does not
retain its runtime UUID.

The Firefox manifest continues to declare the four data categories required for
the wallet's primary local routing function: financial/payment information,
authentication information, browsing activity, and website content. Companion
has no technical/interaction analytics, telemetry, advertising, cloud account,
remote code, or developer-operated data service.

Use only with a Wren desktop build at or after the minimum commit in the bundled
compatibility artifact.
