# Wren Companion 0.1.2

This update improves connection reliability on Etherscan, BaseScan, and other
Ethereum apps.

- Wren now connects correctly on apps that also check for MetaMask
  compatibility. Wren still identifies itself as Wren.
- The popup more reliably shows the active network and the site's Wren/MetaMask
  setting, including pages that use embedded frames.
- Connections now work when a site asks to switch networks before it asks for
  account access, including BaseScan's Base network flow.
- Site setting changes stay tied to the exact page that requested them in
  Chrome and Firefox.
- The last known network list stays visible during brief local disconnects or
  browser background restarts. Accounts, requests, transactions, and page
  content are not stored in this list.

Pairing, page isolation, and the data sent to Wren are unchanged from 0.1.1.
The extension continues to use EIP-1193, EIP-6963, and pairing protocol 3.
