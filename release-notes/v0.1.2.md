# Wren Companion 0.1.2

This compatibility and reliability update fixes wallet connection on dapps that
explicitly select Wren through EIP-6963 but still use MetaMask's legacy provider
marker as a generic EIP-1193 gate. Wren keeps its own EIP-6963 identity.

The popup now primes a lightweight top-tab session before the first dapp request,
derives connection status across same-origin frames, and always keeps the
Wren/MetaMask identity control available on supported pages. This removes false
"Refresh this tab" states on injected or already-connected Etherscan/BaseScan tabs.

The last valid network catalog is stored locally so transient localhost failures
and Manifest V3 background restarts no longer replace known networks with an
unavailable screen. The new `storage` permission is used only for this catalog;
accounts, requests, transactions, and page content are not cached. Protocol-3
authentication, origin/document isolation, and data-transmission declarations
are unchanged from 0.1.1.
