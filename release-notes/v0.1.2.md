# Wren Companion 0.1.2

This compatibility and reliability update fixes wallet connection on dapps that
explicitly select Wren through EIP-6963 but still use MetaMask's legacy provider
marker as a generic EIP-1193 gate. Wren keeps its own EIP-6963 identity.

The popup now derives connection status across same-origin frames without letting
an idle contract iframe downgrade an already usable tab. A transient authenticated
localhost reconnect also retains the last valid network catalog while it refreshes.

The protocol-3 authentication, origin/document isolation, permission boundary,
and data-transmission declarations are unchanged from 0.1.1.
